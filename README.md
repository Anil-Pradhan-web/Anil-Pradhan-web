## About Me

I'm a Computer Science undergraduate who enjoys building the systems behind real-world AI products.

I started with **backend engineering** because I liked understanding what happens behind the screen — APIs, databases, system design, error handling, and the things that keep an application running.

Then I moved deeper into **AI**. Instead of building only simple chatbots, I became interested in what happens when AI becomes part of a larger system:

- How can multiple AI agents work together?
- How can AI use tools and structured workflows?
- How can a vision system turn images into useful evidence?
- How do we keep an AI system reliable when models, APIs, or networks fail?

That is what I like building today.

> **My goal is simple: build AI systems that actually hold up in the real world.**
