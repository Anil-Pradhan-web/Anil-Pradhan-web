## About Me

I'm a Computer Science undergraduate focused on **AI and backend engineering**.

I started with backend development because I enjoyed understanding what happens behind the screen — APIs, databases, system design, error handling, and the logic that keeps applications running.

Then I moved deeper into AI.

What interested me wasn't just generating a response. I became more interested in building the **systems around AI**:

- multiple agents working together
- AI using tools and structured workflows
- computer vision turning images into useful evidence
- backend systems handling failures and unreliable services

Today, I work mainly with **Python, FastAPI, LangGraph, OpenCV, PyTorch, and modern LLM tooling**.

> **Build things that actually hold up — especially when the pieces want to fail.**
